## Key Takeaways
- Creation enforces minimum plan, specification, and review headings.
- Leave changelog `## Git Commit` unfilled in tool input: the tool injects the current full HEAD and rejects even a matching prefilled hash.
- The tool owns exclusive, non-overwriting creation; update existing files with normal file tools.
